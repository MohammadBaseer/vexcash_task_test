# VEXCASH – Mein Konto

This is the "My Account" page for VEXCASH. It shows the logged-in customer's
personal details, family information and employment data, with a menu to
switch between account sections.

The page works on every screen size, from small phones to wide desktop
monitors, and changes its layout to fit.

It's built with React, TypeScript and Vite, and styled with Bootstrap 5.3.0
plus a few of our own CSS files.

## Getting started

You need [Node.js](https://nodejs.org/) installed. Then, in this folder:

```bash
npm install        # download the dependencies (only needed once)
npm run dev        # start the page at http://localhost:5173
```
